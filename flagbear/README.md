# flagbear

A project for collecting some tricks and utilities for data analysis.

## Installation

```bash
pip install flagbear
```

## Features

- **answers**: Bit operations, scalar operations, and random number utilities
- **const**: Pattern matching constants
- **llp**: Lexical analysis and parsing tools
- **sched**: Task scheduling utilities
- **slp**: Serialization, caching, and storage tools
- **str2**: String processing utilities
- **tree**: Tree and graph structures

## Development

```bash
# Install development dependencies
pixi install

# Run tests
pixi run test

# Build package
pixi run pypi-build
```
